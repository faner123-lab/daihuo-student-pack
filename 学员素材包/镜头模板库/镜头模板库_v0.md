# 阿炎 · 镜头模板库 v0（2026-11-07 确认，阿炎工作台 v8 使用）

日期：2026-11-07。来源：初评为“好”的 7 条参考（R04、R06、R17、R18、R19、R20、R21），逐镜拆过（共 166 个镜头）。“一般”那 12 条里的亮点镜头还没拆，下一轮补进来。
参考帧总图：同目录 `阿炎_镜头模板库_参考帧_v0.jpg`，每个模板一行，左上角标了出自哪条参考、第几秒。

## 怎么用

- **复刻模式**：照参考逐镜对位，不需要查这里；但模板库里的“镜内动作”和“进场方式”写法可以直接拿来写 H3 提示词。
- **文案模式**：每句旁白先判断它是干什么的（钩子、痛点、讲知识、卖点、价格、结尾），再从下面对应的模板里挑一个，换成这条文案的内容。**镜头结构用模板，内容才是原创。**
- 同一条片子里，同一个模板最多用两次。

## 一、7 条好参考量出来的节奏规律

| 项目 | 数据 | 用法 |
|---|---|---|
| 镜头时长 | 中位数 0.8–2.1 秒；最快的 R06 有 78% 的镜头在 1.5 秒以内 | 一句旁白常拆成 2–3 个镜头，不要一句一镜 |
| 转场 | 约一半是硬切，三分之一是闪白或亮的糊入，少量黑场 | 换场景、换话题用闪白或糊入；同一场景内硬切 |
| 运镜 | 静止和运动的镜头大约各半；每条片子有 1–9 个“大推、大拉、大横移”的镜头 | 不要每镜都慢推。多数镜头接近不动，少数几镜大动作，集中在开场、产品登场和结尾 |
| 标题 | 3–5 秒内出现“今天我们讲＋关键词”的大标题 | 固定 |
| 光色 | 暖金高光为主，暗画面占比很低 | 默认暖亮，暗场只用在“问题最糟糕”的一两镜 |

## 二、模板（20 个）

### 开场钩子

**T01 超现实天象开场**
- 适合：开头第一句，尤其是“你身材的……”“……的最后一关”这类大命题。
- 画面：主角站在巨大的天象或能量前面，比如金色龙卷风、血红魔王天空、光柱神殿。人小景大，标题字可以放在天上。
- 镜内：能量旋转、光柱扩散；主角抬头或转身。
- 运镜：大推加横移，约 2–3.5 秒。
- 来源：R19 1.5 秒、R13 1.1 秒、R08 2.8 秒。

**T02 夸张动作冲镜头**
- 适合：开头或情绪高点，表现“猛、狠、拼”。
- 画面：主角做一个夸张动作直冲镜头：仰头灌一整瓶咖啡、哑铃挥向镜头、手伸到镜头前。仰拍近景，透视夸张（手或物体特别大）。
- 镜内：动作冲向镜头，液体或汗飞溅。
- 运镜：大推，1–1.5 秒。
- 来源：R17 0.6 秒、R06 1.7 秒、R19 12.0 秒。

**T03 围观反差**
- 适合：讲“形象、颜值、吸引力、被人看”的旁白。
- 画面：一群人（女生、路人、记者）围着主角看，或者主角身后是一整面巨屏人脸墙或粉丝墙。
- 镜内：围观的人表情有先后变化，屏幕闪动。
- 运镜：推或拉加横移，1–2 秒。
- 来源：R06 0.6 秒、R19 10.2 秒、R09 2.9 秒。

**T04 巨型标题字或牌匾**
- 适合：一句话里有一个可以“写出来”的梗词，比如“摆烂”“视觉张力”。
- 画面：一块巨大的金字牌匾或发光大字立在主角身后，主角在旁边做对应的动作。
- 运镜：推近，0.5–1 秒。
- 来源：R20 6.8 秒、R19 3.8 秒。

### 标题

**T05 大特写加关键词标题**
- 适合：“今天我们讲＋关键词”。
- 画面：主角脸部大特写（自信笑），或者产品相关的东西炸开飞向镜头（蔬果、元素），关键词大字叠在画面中央。
- 运镜：推近，0.5–1.5 秒，前面接闪白。
- 来源：R06 4.7 秒、R21 3.5 秒。

### 痛点

**T06 搜索弹窗包围**
- 适合：“不知道怎么选”“买对不买贵”“想补却不知道”。
- 画面：主角拿着手机皱眉，身边飘满搜索结果卡片和问号。
- 运镜：基本不动，弹窗自己在飘，1.5–2 秒。
- 来源：R18 3.0 秒、R19 14.6 秒。

**T07 满屏信息图**
- 适合：讲知识点、讲“要吃多少种”“三个核心点”。
- 画面：把知识点做成满屏信息图，比如食物信息墙、七大营养素轮盘、全息营养屏、黑板写 1、2、3。主角在旁边指或抱头。
- 运镜：推加横移，1.5–4 秒。
- 来源：R06 19.5 秒、R21 9.0 秒、R18 4.8 秒、R21 6.5 秒。
- 注意：信息图里的字要画出来（食物名、元素符号、序号），这需要改掉“画面里不画字”的规则。

**T08 抱头崩溃加东西压垮**
- 适合：“花大量时间研究”“记不住这么多”。
- 画面：主角抱头尖叫，身边堆满东西（药罐、食物图、食谱）。
- 运镜：基本不动，表情是重点，1–2 秒。
- 来源：R06 28.8 秒、R04 25.8 秒。

**T09 日常坏习惯近景**
- 适合：“每天吃外卖”“蔬菜只有几片叶子”。
- 画面：外卖袋、饭盒的近景，可以加一张小卡片放大坏细节（只有几片叶子）。
- 运镜：基本不动，1–1.5 秒。
- 来源：R21 18.0 秒、R06 31.0 秒。

**T10 物件雪崩或倾泻**
- 适合：“一罐接一罐”“单一成分不如……”“能拿下一个月的鱼油”。
- 画面：东西大量倾泻：蛋白粉雪崩、药片倒成小山、金币堆成塔。
- 运镜：大推或拉，0.8–1.5 秒，粉尘和颗粒飞向镜头。
- 来源：R06 8.8 秒、R18 9.5 秒、R17 2.5 秒。

**T11 漩涡异次元伸手**
- 适合：情绪最强的一句，比如“连……都哭晕了”“25+”。
- 画面：蓝色能量漩涡背景，主角伸手冲向镜头，表情痛苦或拼命。
- 运镜：推加横移，1–2 秒，前面接闪白或黑场。
- 来源：R06 13.5 秒、R19 11.8 秒。

**T12 拟人小角色**
- 适合：把营养素、身体部位拟人化，比如“老己记仇”“钙这一块”。
- 画面：一群卡通小角色（愤怒的肌肉怪、可爱的钙团子），数量要多，围着主角或在能量流里。
- 运镜：拉加横移，0.5–1 秒。
- 来源：R19 26.5 秒、R04 23.5 秒。

**T13 禁止符号划掉旧做法**
- 适合：“……可以去掉了”“不用再……”。
- 画面：旧做法（固体钙、煎鸡胸）上叠一个大红色禁止符号。
- 运镜：推近，1 秒左右。
- 来源：R19 16.5 秒、R20 22.0 秒。

**T14 比喻换景**
- 适合：任何可以夸张联想的一句。把旁白放到一个极端场景里：“全勤航班”画成坐在飞机机翼上；“液体钙”画成被巨浪包围；“原料”画成在花田采花；海里的东西画成潜水举瓶。
- 运镜：推近或横移，1–2 秒。
- 来源：R03 4.1 秒、R18 11.6 秒、R17 11.5 秒、R17 19.0 秒。

### 卖点和价格

**T15 元素球环绕产品**
- 适合：“维生素、微量元素”“含 XX 种营养”。
- 画面：一圈写着元素符号的发光球（A、C、D、锌、钙）环绕产品或药片，主角托着或举向镜头。
- 运镜：推近，1–2 秒。
- 来源：R04 15.5 秒、R06 22.0 秒、R19 33.5 秒。

**T16 等号对比价签**
- 适合：“少喝一杯……就能拿下”这类价格换算。
- 画面：日常消费品和产品并排，中间一个大等号，下面是价签。
- 运镜：横移，1–1.5 秒。
- 来源：R17 3.5 秒。

**T17 全息大数字**
- 适合：强调一个数字（20g、16mg）。
- 画面：秤上或空中弹出发光的全息数字。
- 运镜：推近，1 秒左右。
- 来源：R20 35.0 秒。

**T18 使用微距**
- 适合：“小小一粒”“一勺约等于”。
- 画面：倒药片、舀粉、蔬菜飞进杯子的特写，主角的手完成动作。
- 运镜：推近，1–1.5 秒。
- 来源：R18 9.0 秒、R21 24.5 秒。
- 黑底网格拼贴段沿用现有做法，不在这里重复。

### 结尾

**T19 瓶阵冲镜头**
- 适合：最后一句（“需要的兄弟直接冲”）。
- 画面：主角双手托着一排产品伸向镜头，周围元素环绕，背景暖亮。
- 运镜：大推，1.5–2 秒。
- 来源：R19 34.0 秒、R18 27.0 秒。

**T20 时间环或日历**
- 适合：“能吃一个月”“长期健身”。
- 画面：主角身后一个金色时钟环或一排打勾的日历。
- 运镜：基本不动或轻推，1.5–3 秒。
- 来源：R17 14.5 秒、R17 17.0 秒。

## 三、规则调整（2026-11-07 已确认，已写进阿炎工作台 v8）

1. **画面里能不能画字**：T07 信息图、T15 元素球、T04 牌匾、T17 全息数字都需要画字。建议改成“产品包装字用原图；信息字（元素符号、食物名、序号、梗词）可以画”。
2. **默认运镜**：现在 H3 提示词默认写慢推。建议改成“多数镜头基本不动，靠画面里的东西动；开场、产品登场、结尾用大推”。
3. **一句一镜**：现在是一句旁白一个 H3 片段。好参考常把一句拆成 2–3 个短镜头。建议一句话至少配一个主镜加一个插入镜（可以是同一个 H3 片段的不同段落，或者一张静图推近）。
4. **38%/62% 构图**：这些参考里主角常在画面正中，这条规则对阿炎风格建议取消。
