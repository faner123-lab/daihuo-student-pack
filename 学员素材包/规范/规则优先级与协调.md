# 规则优先级与协调

素材包里同时有多个风格的技能（目前是阿炎和 3D 剧情带货，以后还会增加）。它们共用同一批脚本、音效和背景，但画面规则不同。这份文档说明怎么避免冲突。

## 一、谁听谁的

1. **用哪个风格，就听哪个风格技能里的规则**（`技能/<风格技能>/SKILL.md` 和 `风格/<风格>/`）。
2. 风格技能没写的，才看本文件夹 `规范/` 里的通用规范。
3. 风格规则和 `规范/` 里的规则冲突时，**风格规则赢**。
4. 学员当次明确的要求，高于以上所有规则。

> 例：字幕。阿炎规定关键词标黄，3D 剧情风格规定白字黑边不标黄。做哪种风格就按哪种，不要混用。

## 二、哪些是共用的，哪些是各风格自己的

| 类型 | 共用（放在素材包公共位置） | 各风格自己的（放在各自技能或风格文件夹） |
| --- | --- | --- |
| 音效 | 真实音效库、音效清单 | 哪个镜头配哪个音效的选法 |
| 脚本 | 环境检查、配音示例、音效混音工具、推拉模糊等函数 | 渲染脚本范例、花字、拼贴 |
| 通用规则 | 只用真实音效、整体 -14 LUFS、不读密钥、文案不改 | 字幕样式、转场种类、画布尺寸、构图、分镜方法 |
| 背景/素材 | 黑色网格背景视频 | 风格专属的模板、示例 |

规则：**只有两个以上风格都成立的东西，才放进公共位置。** 只有一个风格用的，放进它自己的文件夹，不污染公共部分。

## 三、已经装了阿炎的学员，再装新风格会怎样

- 新风格是**新增文件**：新的技能文件夹、新的风格文件夹、新的规范文档，不会改动阿炎已有的文件。
- 技能名字各不相同（`ip-daihuo-video-studio`、`3d-story-daihuo-studio`），装进 `~/.claude/skills/` 不会互相覆盖。
- 更新方法：重新下载仓库，或在仓库目录运行 `git pull`，再把最新的 `学员素材包` 拖进对话。
- **别把自己的东西放进素材包里面。** 自己的音效、IP 图、项目文件放在自己的项目文件夹。这样 `git pull` 不会和本地改动打架，也不会被更新覆盖。
- 如果学员自己改过素材包里的文件，更新前先备份那个文件，更新后再手动合并。

## 四、新增内容时的约定（给维护者）

1. **新增风格**：在 `技能/` 下加一个新技能文件夹，在 `风格/` 下加一个同名风格文件夹，在下面的清单里登记。公共部分不动。
2. **新增音效**：文件名不要和现有的重名；先按内容去重（同一个音效不要放两遍）；然后在 `音效库/音效清单.md` 里登记用途。音效清单是唯一的索引。
3. **新增或改动脚本**：改共用脚本时，要保证已有风格的范例还能跑；只有一个风格用的函数，放在风格自己的文件里。
4. **版本**：每次较大更新，在仓库 README 的更新记录里写一行（日期、改了什么、影响哪个风格）。
5. **敏感信息**：仓库里不放音色 ID、密钥、个人电脑的路径、具体客户项目名。
