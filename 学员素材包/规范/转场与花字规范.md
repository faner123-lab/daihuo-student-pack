# 阿炎 · 转场 + 花字 + 开场标题 + 黑色网格拼贴 规范｜v1

脚本在本包的 `脚本/` 里，配合 `huazi.py`、`transitions.py`、`sfxmix.py` 使用。音效选择见 `音效库/音效清单.md`。

## 一、一条 40 秒带货片的结构（阿三参考）

1. 钩子：两行花字（0–2.5 秒），第 1 行普通词白色、关键词蓝色，第 2 行金色大字
2. 裂开标题：“今天阿炎讲 + 关键词”（约 2 秒）
3. 问题段：每镜 1.5–2.5 秒，场景动画
4. 产品登场：金光 / 闪白
5. 黑色动态网格拼贴（占 35–45%）：抠图立绘 + 左实拍卡 + 右详情卡，卡片硬切，红圈标注
6. 价格段
7. 手托多瓶、指向左下角结尾

## 二、转场（切点是硬切，新镜头进来时糊 / 亮 / 放大，再在 0.35–0.45 秒内恢复）

| 转场 | 时长 | 画面参数 | 默认音效 | 用在哪 |
|---|---|---|---|---|
| 硬切 | 0 | 直接换 | 不配 | 拼贴段内换卡片，问题段多数 |
| 甩镜糊入 | 0.35 秒 | 竖向模糊 260 px → 0，亮度 +45% → 0 | 呼_转场音效 | 情绪、动作镜头 |
| 推近缩放糊入 | 0.35 秒 | 1.30 倍 → 1.0，放射模糊 0.28 → 0，亮度 +25% → 0 | 咻的一声 | 动作、强调镜头 |
| 闪白糊入 | 0.35 秒 | 白色覆盖 75% → 0，高斯模糊 22 → 0 | 仙尘音效 | 产品登场、金光 |
| 黑场亮起 | 0.45 秒 | 全黑 0.1 秒，再亮起 0.35 秒 | 砰_拳击（换话题）或 冲击_带低频 | 换话题、段落切换 |
| 漏光扫过 | 0.5 秒 | 暖黄光带 #FFD678 斜着从右往左扫过，前后各 0.25 秒 | 呼_转场音效 | 钩子第 1 句 → 第 2 句 |
| 横向甩糊（出 + 入） | 0.4 秒 | 出场最后 0.18 秒横向模糊 0 → 300 px，入场 0.22 秒 300 → 0 | 嗖_转场1 | 拼贴段 → 结尾 |
| 压黑 + 故障抖动 | 见下 | 见下 | 转动齿轮（截 0.36 秒） | 裂开标题 |
| 卡片闪白 | 0.2 秒 | 只有卡片区域先发白再换图，人物不动 | 叮_提示 | 拼贴段关键数字卡 |

排布规则：
- 问题段每 2–3 个硬切插一个糊入，甩镜、推近、闪白轮换，不连续用同一种。
- 音效只配糊入、黑场、漏光；硬切不配。
- 转场和音效是成对设计的：同一个转场固定一个默认音效，换音效就要重新对齐。
- 节奏放慢：转场 0.35–0.5 秒，不要做成 0.2 秒的快闪。

## 三、花字（开场两行）

- 字体 Noto Sans CJK SC Black，两行错开：第 2 行向右、向下缩进，整体放在画面高度约 55–60% 处
- 普通词：白色渐变（255,255,255 → 222,226,232），细深色描边 + 柔和阴影
- 关键词颜色：蓝 #E1F6FF → #3496FF；金 #FFF8BE → #FFB014；粉 #FFD6EC → #FF4896；绿 #DCFFC8 → #28D23C
- 斜切（italic shear）约 0.12–0.14
- 出场：第 1 行 0.12–0.34 秒（放大 1.18 → 1、去模糊、淡入）；第 2 行 0.6–0.9 秒（从右滑入约 60 px，带回弹）；最后 0.22 秒横向甩糊出场 + “呼”
- 声音：第 2 行滑入配“咻的一声”，结尾甩糊配“呼_转场音效”

## 四、裂开标题（“今天阿炎讲” → 关键词）

1. 前一镜压黑 0.1 秒，再约 0.55 秒亮起
2. 白色标题（约 104 px，细描边，上白下灰渐变）故障抖动 0.03–0.7 秒：上下两半在指定帧左右错开 ±10–35 px，配“转动齿轮”（截 0.36 秒）
3. 0.7–0.85 秒裂开：上下两半分开，间隙 = 字高 × 0.30
4. 金色关键词（100–118 px，描边 8，斜切）从缝里弹出 0.74–1.0 秒（回弹曲线），配“字幕音效_嘭”
5. 停留到约 1.9–2.0 秒
- 诺特兰德默认值：标题“今天阿炎讲”，关键词“形象优先”，`line1=[("25岁之前的",70,白),("主线任务",94,蓝)]`，`line2=[("变帅",132,金)]`

## 五、黑色动态网格拼贴

- 背景：`背景/动态黑色网格_1280x720_60秒循环.mp4`（278 帧，循环周期 25.27 帧 / 格），本包已带 60 秒循环版
- 版式：中间抠图立绘（阿炎手拿产品），左边实拍卡，右边详情 / 含量卡；卡片硬切，关键数字处加红圈、卡片闪白 + “叮”
- 卡片素材要用真实实拍和产品详情图，由用户提供

## 六、脚本用法

- `huazi.py`：生成花字 + 裂开标题的帧序列
- `transitions.py`：生成 6 种转场的演示条
- `sfxmix.py out.wav 总秒数 文件:时间:模式:增益 ...`：按时间点混音，模式 peak（呼啸类对最响处）/ onset（撞击、叮类对起点）
- 渲染长视频用 `setsid nohup ... &` 放后台，再轮询
