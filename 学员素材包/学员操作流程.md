# 学员操作流程（从拿到链接到出成片）

你只需要做四件事：提供素材、回答 Claude 的提问、去 H3 点生成视频、听一遍配音。其余都由 Claude 带着你完成。

## 第 1 步：选风格

| 风格 | 画布 | 适合 | 启动提示词 |
| --- | --- | --- | --- |
| 阿炎（日系漫画风） | 横屏 1280×720 | 夸张、超现实、黑色网格拼贴 | `启动提示词.txt` |
| 3D 剧情带货 | 竖屏 1080×1920 | 一个连贯的小故事、生活场景 | `启动提示词_3D剧情带货.txt` |

不确定选哪个，两个都看一下 `风格/` 里的说明，或者问老师。

## 第 2 步：准备清单

| 要准备的 | 怎么准备 | 必须吗 |
| --- | --- | --- |
| 产品正面图 | 包装字清楚的原图 | 必须 |
| 产品文案 / 口播稿 | 你的原文，Claude 一字不改 | 必须 |
| 你的 IP 形象 | 已有就准备设定图，没有开工后让 Claude 带你设计 | 必须 |
| 参考视频 | 阿炎风格必须；3D 剧情风格可选 | 视风格 |
| 火山语音合成账号 | AppID、Access Token、你自己克隆声音的 Speaker ID | 做配音时必须 |
| 背景音乐 | 有明显爆点的已授权音乐 | 必须 |
| 出图工具、视频生成工具 | 如 Codex（出图）、H3（出视频） | 必须 |
| 电脑环境 | Python 3、ffmpeg、numpy/Pillow/scipy、中文粗体字体，不会装没关系，Claude 会检查并告诉你 | 必须 |

## 第 3 步：开始做（一句话丢给 Claude）

新开一个 Claude 对话，把下面这段话整段复制发送，最后一行选风格。Claude 会自己下载、安装技能，并带你从第 0 步开始做。

```
我是带货视频课程的学员，要用老师开源的「学员素材包」做一条带货视频。

仓库地址：https://github.com/faner123-lab/daihuo-student-pack
最新版下载页：https://github.com/faner123-lab/daihuo-student-pack/releases/latest

请按下面的顺序做：

1. 把仓库下载到我电脑上（能运行命令就 git clone，否则下载最新版的 Source code zip 并解压）。
2. 如果访问 GitHub 被拦截（403，或提示「此会话未开启对该仓库的 GitHub 访问」），不要尝试绕过，也不要换镜像或缓存地址。直接告诉我三个办法：
   a. 在设置里开启对 github.com 的访问，我开好后你重试；
   b. 我自己在浏览器打开上面的下载页，点 Source code (zip)，解压后把「学员素材包」文件夹拖进这个对话；
   c. 我先添加一个放下载文件的文件夹，你用内置浏览器去下载，下载前先告诉我文件名、来源和大小，等我确认。
3. 拿到「学员素材包」后，运行里面的安装脚本，把技能装好（Mac/Linux 是 install.sh，Windows 是 install.ps1）。装不上就直接读 学员素材包/技能/ 里对应风格的 SKILL.md，照它做。
4. 然后读取 学员素材包 里对应风格的启动提示词，严格按里面的要求，从第 0 步开工检查开始带我做。每个阶段结束时用一两句话告诉我进度和我下一步要做什么，遇到「【停】」的地方一定等我确认。

我选的风格是：阿炎（横屏）
```

做 3D 剧情带货的，把最后一行改成：`3D 剧情带货（竖屏，用自己的 IP）`。

开工前 Claude 会问要不要把技能和素材包装到你自己的电脑上，同意后以后不用再拖文件夹或去 GitHub 下载。

### 被拦截（403）怎么办
如果 Claude 报「此会话未开启对该仓库的 GitHub 访问」或返回 403，这是你当前 Claude 环境的网络设置，Claude 自己改不了，也不会去绕过。三种办法任选一个：

- 开启 GitHub 访问：在 Claude 的设置里允许访问 github.com（公司或组织账号需要管理员开启），开启后让 Claude 重试。
- 自己用浏览器下载（不需要任何联网权限）：打开 https://github.com/faner123-lab/daihuo-student-pack ，点 Code → Download ZIP，解压后把「学员素材包」文件夹拖进对话，再粘贴你选的启动提示词。
- 让 Claude 用内置浏览器下载：先在桌面端添加一个放下载文件的文件夹（比如「下载」），再让 Claude 去下载页下载并解压。下载前它会告诉你文件名、来源和大小，等你确认。

## 第 4 步：Claude 会带你走的流程

| 阶段 | 你做什么 | Claude 做什么 |
| --- | --- | --- |
| 0 开工检查 | 给产品图和文案，确认 IP，确认配音账号，贴环境检查结果 | 问选择题，检查剪辑环境 |
| 1 分镜 | 选开场方案，确认分镜表 | 拆参考或写故事，设计分镜，自审 |
| 2 出图 | 用出图工具点生成，把图放进项目文件夹 | 写出图任务单，审图 |
| 3 H3 提示词 | 去 H3 点生成视频，把片段放回项目文件夹 | 写 H3 提示词，收片、查缺镜 |
| 4 配音 | 确认文稿，运行一次配音脚本，听一遍 | 写配音文稿和脚本，处理音频 |
| 5 剪辑 | 看成片，提修改意见 | 渲染、音效、转场、混音、质检 |
| 6 交付 | 取走成片 | 整理项目文件夹，写阅读说明 |

每完成一个阶段，Claude 会用一两句话告诉你进度和你下一步要做什么。

## 配音账号怎么设置

两条规矩：声音必须是你自己的或已获授权；密钥只放在自己电脑的环境变量里，不要发给任何人，也不要发给 Claude。

- Windows（PowerShell，设完重新打开终端和 Claude）：`setx VOLC_APPID "你的AppID"`，`setx VOLC_TOKEN "你的Token"`，`setx VOLC_SPEAKER_ID "你的SpeakerID"`
- Mac / Linux：把三行 `export VOLC_APPID="..."`、`export VOLC_TOKEN="..."`、`export VOLC_SPEAKER_ID="..."` 加到 `~/.zshrc` 或 `~/.bashrc`
- 测试：`python3 学员素材包/脚本/check_env.py --only-tts --test-tts`，把屏幕上的 [OK]/[缺失] 贴给 Claude 即可

## 遇到问题

- Claude 没按流程走：对它说「请严格按技能里的步骤，从第 X 步重新开始」。
- 环境检查报缺东西：照它给的提示补装，补完让它重跑。
- 更新：重新下载仓库，或在仓库目录运行 `git pull`，再重新拖入最新的 `学员素材包`。
