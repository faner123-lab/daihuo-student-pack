# 学员素材包（先读我）

这个包 + 一个技能 = 在你自己的电脑上做出和老师一样效果的带货短视频（自己的 IP、原创夸张画面、配音、音效、剪辑一条龙）。

## 里面有什么
- 技能/ip-daihuo-video-studio/SKILL.md ：要安装到你的 Claude 里的技能（安装方法看《学员使用说明书.pdf》第 2 页）
- 脚本/ ：剪辑用的代码（花字、转场、拼贴、混音）+ 两个完整范例 + 环境检查 check_env.py + 配音示例
- 音效库/ ：11 个真实音效 + 音效清单.md
- 镜头模板库/ ：20 个夸张镜头模板 + 参考帧总图
- 背景/ ：黑色动态网格背景视频（拼贴段用）
- 规范/ ：转场与花字规范、音效用法对照

## 不在包里、需要你自己准备
1. 一条你想借鉴的爆款参考视频（mp4）
2. 你的产品正面图 + 产品文案
3. 你自己的 IP 形象（没有就让 Claude 带你设计）
4. 火山语音合成账号：AppID、Access Token、你自己克隆的声音的 Speaker ID
5. 背景音乐（有明显爆点，自备或已授权）
6. 出图工具（如 Codex）和视频生成工具（如 H3）

## 第一次使用（最简单的办法，不用装任何东西）
1. 新开一个 Claude 对话。
2. 把整个《学员素材包》文件夹（或 学员素材包.zip）拖进对话框。
3. 再把 启动提示词.txt 里的内容复制粘贴发送。
4. 然后照 Claude 的提问一步步来：上传参考视频、产品图、文案，点选择题。
（PDF 说明书只是给你看流程的，不看也能用。）

## 想做 3D 剧情带货（竖屏、用自己的 IP）？
用 启动提示词_3D剧情带货.txt 代替 启动提示词.txt，其余步骤相同。该风格自带「渲染模板」（风格/3D剧情带货/渲染模板/），先运行 selftest.py 自检环境。两个风格共用音效库，冲突时以各自风格的技能为准（见 规范/规则优先级与协调.md）。
