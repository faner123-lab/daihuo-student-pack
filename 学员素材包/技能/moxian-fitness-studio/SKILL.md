# 墨线健身科普 · 解说视频流水线（学员版）

纯黑底 + 日漫硬派墨线人物 + 单一强调色（**黄 = 发力 / 主角**，**红 = 脂肪 / 危险 / 错误**，**绿 = 正确**）。成品约 60–105 秒、1920×1080（横屏）、30fps。每句文案配一张「字面演出来」的画面，贴纸、特写、镜头运动由代码合成（Python PIL + numpy → ffmpeg）。

## 素材包位置
本技能依赖《学员素材包》文件夹（里面有 脚本/、音效库/、背景/、规范/、风格/）。找它（记为 PACK）按这个顺序：①环境变量 PACK；②本机固定位置 `~/学员素材包`（Windows 是 `%USERPROFILE%\学员素材包`，安装脚本会放在这里）；③学员拖进对话的文件夹或 学员素材包.zip（zip 先解压）。三处都没有，就让学员再拖一次。下文的路径都相对 PACK。

## 装成学员自己的技能（第一次开工时先问，只做一次）
1. 先问学员「要不要把这套技能装到你自己的 Claude 里，以后直接用？」，同意再做，不同意就跳过，别的流程照常。
2. 能运行命令的环境：把 PACK 复制到 `~/学员素材包`（已经在那里就跳过），再把 PACK/技能/ 下的每个技能文件夹复制到 `~/.claude/skills/`（Windows 是 `%USERPROFILE%\.claude\skills\`），已存在的会被更新。装完告诉学员重启 Claude。素材包里有 install.sh / install.ps1 时直接运行它们也一样。
3. 不能运行命令的环境：告诉学员到 Claude 设置里的技能页，把 PACK/技能/ 里本风格的 zip 逐个上传；素材包文件夹放在固定位置，下次拖进对话即可。
4. 装好后告诉学员以后怎么开工：直接说「用 moxian-fitness-studio 技能做一条墨线健身科普视频」。

## 先说清楚：这个风格没有现成的渲染引擎
3D 两个风格有现成的渲染模板（`风格/3D剧情带货/渲染模板/`，竖屏）。**墨线风格是横屏 1920×1080，素材包里没有现成的墨线引擎。** 动效代码由你（Claude）按下面的规则，在学员的电脑上一期一期写：开工先做环境自检和冒烟测试，再先出前 30 秒样片确认风格，学员认可后再渲染全片。素材包里的 `音效库/` 可直接用；`风格/3D剧情带货/渲染模板/mix.py` 里音效摆放、人声闪避、−14 LUFS 响度的做法可以参考，但它读的是 3D 渲染模板自己的 marks.json，不能直接套用，混音脚本也要按墨线项目的时间码另写。不要向学员承诺「一条命令出片」。

## 分工
- Claude（你）：文案分句、分镜总表、给图像工具写出图任务单、审图、写配音脚本、写代码做动效、混音、导出。
- 图像工具（如 Codex、ChatGPT 图像等）：只按任务单出图，不审图、不自检。
- 学员：提供文案或参考视频、把任务单发给图像工具、自己运行配音脚本（用自己的火山账号和音色）、给意见。

## 流程
**0. 开工检查【停】**：文案或选题、学员自己的 IP、配音账号（火山 AppID / Access Token / 自己克隆的 Speaker ID，只放环境变量 `VOLC_APPID` / `VOLC_TOKEN` / `VOLC_SPEAKER_ID`，不写进脚本、不上传）、环境（ffmpeg、Pillow、numpy、中文粗体字体），跑冒烟测试；检查 PACK/音效库 是否齐全。

**1. IP 设计与定稿（一次性）【停】**：学员已有 IP 就用学员自己的；没有就带他设计。墨线风格建议：
- 主角：身材好但不夸张的运动型，身上有**一处黄色配饰**（如臂章、短裤、头带）作为「主角 = 黄」的识别点；表情要生动。
- 配角全部单独设计（喜剧担当大块头、路人：胖子 / 瘦小 / 上班族等），**配角身上不要有黄色**，以免串色。
- 产出：母图 + 表情表 + 三视图 + 群像合影。同一个视频固定一个 IP 体系，神态随文案变化。
- 学员的 IP 形象归学员所有，不要套用别人的 IP。

**2. 文案**：学员给的文案一字不改，只「演」文案，不质疑内容；只给参考视频时先拆讲解结构，画面用自己的风格重做。

**3. 配音【停】**：**逐句生成**（每句一个 mp3，S01…Sxx），数字写汉字读法；写逐句脚本 .py（附双击 bat），**由学员自己运行**（火山声音复刻，rate=30 约 1.3 倍，不后期变速），再读取 mp3。不要整段合成再切——会造成声画对不上。每句用 ffmpeg 只裁两端静音（start-only silenceremove + areverse 技巧，不要裁到句内逗号停顿），得到 clips/Sxx.wav 与 clipdur.json。

**4. 时间码（细到子句）**：按 ，。！？：、； 切子句，用 silencedetect（noise=-36dB，d=0.09）得每个子句起止（失败回退按字数比例），缓存 segs.json。画面切换、标签出现 / 消失、音效全部锚定到子句起点或词的比例偏移（提前约 0.05s）。句间默认间隔约 0.22s，不额外加停顿；开场约 0.45s，不要久留。

**5. 分镜【停】**：先写《分镜设计方案》再出图（风险与时长 → 结构与节奏 → 转场 → 花字 → 画质 → 教学细节 → 逐句分镜 → 出图清单）。写完自己再做一轮优化：观众替身故事线（开头的痛点人物在结尾兑现变化）、开场 1.5 秒内强对比、贯穿全片的记忆点组件、长句的「子句节拍表」（每个子句一个画面变化）。一句话 = 一个镜头 = 一张字面演出来的图；动作示范出同机位同大小的多姿势关键帧；文字、数字、箭头、圈全部后期加。时长预估：火山 rate=30 约每秒 7 字。

**6. 出图任务单**：轻任务单（每张最多 2 张参考图、不回看、不自检、不重画，只回复文件名和用时），末尾必须有一条可直接复制发给图像工具的「发送给图像工具的消息」；各批合并成一条消息一次全出，有问题再返修。同机位成对图要写明道具也一致（同一张瑜伽垫、同样式的单杠立柱、同位置的矮凳）。

**7. 审图**：你来审——字面表达文案、神态对、同机位一致、无多余文字、黄色没串色、姿势差异足够大；**并逐张放大检查头和身体方向是否一致**（常见错误：下犬式脸朝前盯着手、悬挂时身体正面但头是侧脸）。不合格写「只改这一处」返修单；头部方向要写具体（如「脸朝正下方，鼻尖指向地面」）。同一张图返修越改越怪时，改为参考主角设定图从头重新生成，不再参考旧图。

**8. 剪辑**：先出前 30 秒样片确认风格，再做全片；静帧抽检后再整片渲染（分层：STAGE 底图 + OV 叠加层 + 转场 + HUD + 字幕）。渲染可能超时：分两段后台渲染再 concat。检查静帧时留意推近镜头把横躺人物左侧裁掉（缩放锚点取小值）、标签压字幕或导航。

**9. 混音**：配音 + BGM（人声时自动压低）+ 真实音效，响度 −14 LUFS。音效只用 PACK/音效库 里的真实音效（或学员自己有授权的音效），不合成；音效稀疏、不重复、与转场成对设计，转场 0.35–0.5s。BGM 从头播放。

**10. 质检与交付**：抽静帧检查、用 ffmpeg ebur128 复核响度。高清版交给学员；体积大的另存小体积存档版（720p，约 10MB）；大文件放学员自己的项目文件夹。

## 设计规则
- 每句文案一个画面，直接演字面意思，不要双重比喻；画面持续有动。
- 同一时刻只有一个标注，新的出现、旧的消失；贴纸出入都有动画（pop / stamp / burst / slide / drop）。
- 固定组件：顶部进度条、N 个动作导航徽章（按本期动作数）+「第 n / N 个动作」、计次徽章；人物约占画面一半高；多姿势关键帧 + 残影；身体部位上色（黄 = 发力 / 拉伸，红 = 脂肪 / 错误）。
- **右侧标签列**：标签、计时环、对比卡统一放在右侧固定列（x≈1450），不压人物、不压主角头顶；右下角常驻组件的提示文字放在组件左侧，不挡上方标签。
- **常驻记忆组件**（建议）：右下角一个侧面解剖小人，初始灰色，每讲完一个动作对应部位亮黄 +「已唤醒：××」+ n/N；解释原理的镜头里把它放到画面中间并放大，结尾全亮放大收束。
- **难度阶梯条**：左上「新手 → 标准 → 进阶」，讲到哪级哪级亮，对应文案里「刚开始… / 熟练后… / 进阶…」。
- **视觉符号统一并重复**：拉伸 = 黄色弹簧（沿肌肉线拉长）；「慢慢解锁」= 锁头打开动画 + 咔哒声；痛点 = 漫画式红色酸痛折线（不要用「石化裂纹」，渲出来像缠了树枝）。
- 错误示范：先绿线 ✓ 正确，再闪 0.7 秒红线错误示范，再切回；「换腿」用水平翻转转场演出来。
- 强调身体部位时，除人物上色外，旁边弹圆形特写章（带引线，0.4s 弹出，引线 0.4s 画出，慢一点才看得清）。
- 主角讲解镜头与示范镜头交替调节节奏，但讲解镜头至少约 1.8s，更短就不加，改连续演示 + 特写章；进出用 0.45s 滑入 + 压暗转场，禁止硬切。
- **字幕一次一行**：每个子句单独一行（不分两行），大字描边、位置固定在底部，跟配音子句同步切换；字幕只用中文。
- **画面变化要大**：转场（推拉位移 / 溶解 / 发光 / 软擦除 / 光扫 / 光圈 / 聚焦）、镜头推近、滑入、闪白、色块变化幅度要明显；每句都要有「转化感」（站立 → 弓步、蓝灰 → 发力黄、动态 ↔ 静态对比），不要小幅微动。
- **教学层**（帮助理解和记忆）：动作标题卡（大序号 + 动作名 + 练哪里 + 已完成动作清单）、肌肉位置卡、计时环、角度 / 距离标注、动作预览卡（先把后面要讲的几个动作依次弹出预览再讲）、对比图（动态 vs 等长等）、总表收尾、行动号召印章。
- 示范类视频由主角自己做全部动作；静止发力用微颤（tremble）+ 黄色发光表现；主角讲解镜头（半身 / 全身姿态图）按需穿插。
- 出图常见返修：某镜头弱就单独出补图任务，不整批重来；姿势成对图用脚底 / 锚点对齐后混合。
- 配音 1.3×；只演文案，不质疑文案或产品。
- 安全过滤被拦：换说法（如「仰卧屈膝」「石膏解剖教学模型」）、用代码镜像已有图，或用代码合成特写。

## 写动效代码的要点
- 每期代码按期数拆成：核心合成（STAGE）、叠加层（OV）、渲染、混音；一期复制上一期改写（字幕原文、姿势组、导航、卡片、转场、记忆组件部位坐标）。
- 用带网格的原图（0.05 一格）读出关键点的归一化坐标，再换算到屏幕坐标；先抽静帧拼图检查，再分两段后台渲染。
- 灰度化 / 缩略图等 blend 时用图片自身尺寸（不要写死宽高）；`np.random` 的种子取绝对值。
- 常用特效：缓动、文字、氛围（微粒 / 暗角 / 颗粒）、镜头推拉 / 冲击 / 抖动、速度线 / 冲击波 / 闪白 / 光扫、贴纸 burst / stamp / label、手绘圈 / 箭头 / 红叉 / 对勾、字幕。多姿势图用脚底锚点钉在同一落脚点。
- 体积控制：颗粒别太强，码率封顶 12–16M，存档版 3–4M。

## 合规
- 配音声音必须是学员本人的或已获授权的；密钥只放自己电脑的环境变量。
- 健身科普内容不夸大功效，不做医疗承诺。
- 使用别人的文案或参考视频，只借鉴结构，画面用自己的 IP 重做。
- IP 形象、音乐、音效都要是自己的或有授权的。
