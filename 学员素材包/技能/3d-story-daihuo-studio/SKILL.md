# 3D 剧情带货工作台（学员版）

目标：学员给**产品图 + 产品文案**，用**自己的 IP** 做出竖屏 1080×1920 的 3D 写实带货视频。画面不是一句一张的幻灯片，而是一个连贯的小故事：主角从某个状态出发，经过一系列动作，遇到产品，变成另一个状态。

## 素材包位置
本技能依赖《学员素材包》文件夹（脚本/、音效库/、背景/、规范/、风格/）。学员通常是把整个文件夹（或 学员素材包.zip）拖进对话：先在附件/上传目录里找到它（zip 先解压），记为 PACK；找不到就让学员再拖一次。下文路径都相对 PACK。

## 和阿炎技能的关系（先读）
- 同一个素材包里还有 `ip-daihuo-video-studio`（阿炎风格）。两个技能**共用** PACK 里的脚本、音效库、背景；各自的画面风格、字幕、转场规则写在各自的技能里。
- **规则冲突时：本技能的规则 > `规范/` 里的通用规范。** 详见 `规范/规则优先级与协调.md`。
- 阿炎是横屏 1280×720，本技能是竖屏 1080×1920，分辨率不同，不要把阿炎的坐标和字幕位置直接搬过来。
- 风格细则和与阿炎的差异表见 `风格/3D剧情带货/风格说明.md`。

## 工作方式
1. 严格按步骤顺序，不跳步，不自己改流程。
2. 每完成一步，用一两句话说：做完了什么、文件放哪、学员下一步要做什么。
3. 需要学员选择时用选择题（没有选择题工具就列 A/B/C 让学员回字母），一次问完。
4. 标【停】的地方必须等学员确认。
5. 不读取、不打印、不复制任何密钥，只确认「存在、能调用」。
6. 学员的文案一字不改（发音修正和断句除外），只在交付时简短提示一次合规风险。

## 第 0 步：开工检查【停】
一次问完：

### 0.1 素材
- 产品正面原图（包装字清楚）。如果要锁包装，再要一张**高清纯白底正面图**（命名 `P01_产品清晰图_正面.png`），一张就够。
- 产品文案 / 口播稿。
- 参考视频：可选。有就借鉴它的节奏和转场，没有就按文案和下面的必备清单设计。

### 0.2 IP 形象（必须有）
- 学员已有 IP：让他提供角色设定图或母图（3D 写实质感的最好；其他画风就按他的画风做，并在后面提示词里锁定）。
- 没有 IP：带他设计。问：性别年龄、体型、发型发色、标志性特征（服装颜色、配饰）、说话方式（默认闭嘴、纯旁白）。写出「IP 外貌规格」（脸、发型、体型、默认服装、不能变的识别点、禁止项：换脸、廉价塑料感、错误中文包装字），先出一张纯色底全身**角色母图**，学员确认后，后面所有分镜图以母图为准。IP 不得模仿真人明星或已有角色。
- 一条视频从头到尾只用一个固定 IP，不切换、不混用。要做「导师 + 学员」之类双人剧情，只用两个固定角色，各自外观全片不变。
- 需要表现前后变化（瘦/壮、乱/整齐）时，在母图之外多出一张「变化后」的同一个角色。

### 0.3 配音 API（必须当面确认）
默认用火山语音合成（声音复刻）。逐项问：有没有 AppID、Access Token、自己克隆的声音的 Speaker ID？是否已设置环境变量 VOLC_APPID、VOLC_TOKEN、VOLC_SPEAKER_ID？
- 密钥在学员自己的电脑上。让学员在自己电脑上运行 `python3 脚本/check_env.py --only-tts --test-tts`，把输出（只有 [OK]/[缺失]）贴回；出现「真实合成一句配音 [OK]」才算配好。
- 声音必须是学员本人的或已获授权，提醒一次。
- 没配好：先做分镜、出图、H3 提示词，配音和剪辑放后面。

### 0.4 剪辑环境（你来跑）
运行 `python3 PACK/脚本/check_env.py`，整理成就绪清单：Python 3、ffmpeg/ffprobe、numpy/Pillow/scipy、中文粗体字体（Noto Sans CJK SC Black，或设 FONT_PATH）、素材包里脚本/音效/背景是否齐全。背景音乐不在包里，让学员自备一首有明显爆点的已授权音乐。

## 第 1 步：剧情型分镜（核心）【停】
先读 `风格/3D剧情带货/风格说明.md`。两种写法都不要用：①一直在一个场景里、重点不突出；②每句话一张带特效的独立插图、场景跟着句子跳（像幻灯片）。

### 四步写法
1. **先写故事，再拆镜头**：一句话写出「谁、从什么状态、经过什么、变成什么」，再把文案按故事分段：现状 → 原因 → 办法 → 选哪款（产品登场）→ 怎么用 → 结果 → 买。旁白里的「你」就是画面里的主角。
2. **每句先判断类型，再定画面**（分镜表加一列「句子类型」）：

| 句子类型 | 画法 |
| --- | --- |
| 状态句（瘦、手腕细、吃不下） | 人物演出来 |
| 体内句（热量盈余、吸收） | 在当前画面上叠体内特效（透视、能量槽、营养流），不另开新图 |
| 时间结果句（稍微练练、一个月后） | 演结果，可加镜中叠影等特效 |
| 数量句（五六碗饭、米面肉蛋奶） | 桌上真的摆出来，不做发光图解 |
| 数据句（专利、梯度、价格） | 画面上方贴卡，下方继续演动作（开罐、舀粉、摇杯） |
| 其余讲道理的句子 | 不图解，继续演正在发生的动作 |

   全片特效控制在 3 处左右。
3. **每镜写清「接上一镜的什么」**：动作一镜接一镜（端碗 → 吃 → 上秤 → 拿杯 → 递杯 → 取罐 → 开罐 → 舀 → 摇 → 喝），道具贯穿全片（镜子、秤、碗、杯、产品罐）。
4. **场景少，换场景要有理由**：大多在同一套房子里（卧室镜子、餐桌、厨房台面），去店里、去工厂才换地方。产品段在一个台面上讲完，结尾回到开头的场景（开头镜子前嫌瘦 → 结尾同一面镜子前变壮）。

### 必备画面清单（分镜阶段就排进去，不要成片后补）
1. **钩子要有画面冲突**：失败、对比、镜前嫌弃等，不要只靠角色正面半身加旁白开场。具体用哪种，给学员 2–3 个方案选。
2. **使用与微距插入镜头**（每个约 1–1.5 秒）：开盖、舀、倒、合盖；由当前角色的手完成。
3. **证据贴图要有强调动效**：检测报告、销量页出现后加框、放大、对勾、数字弹出，只滑入观众不知道看哪里。
4. **结尾转化段**：规格/价格卡 + 红色向下箭头 + 关键词，出现在最后三分之一。不写「点击购物车」之类文字，购物引导放发布文案；价格是否露出先问学员。
5. **机位多样**：相邻镜机位不重复；每条至少 1–2 个背面或低角度、1–2 个微距。
6. 品质镜头（工厂、检测）需要学员提供素材，开分镜前先问有没有。

### 节奏与其他要点
- 一句一个镜头为主，只在重点句加插入镜；不在一句里硬切无关补充镜。
- 镜头长度随文案长短变化，最长约 10 秒；一个镜头里装连续的多个动作、表情变化，不靠大量硬切。
- 全片 1.5 秒以内的短镜占 25% 以上，信息密集处多切短镜。
- 至少一半的切点配真实音效。
- 构图：主体居中、正面对称为主；避开字幕区（下方）。
- 一句旁白太长就拆 A/B 两镜，两镜**共用同一张首帧**，剪辑时 A、B 直接接，不加转场。
- 分镜表列：镜号、旁白句、句子类型、接上一镜什么、景别/机位、画面、表情、什么在动、产品有无、转场入、字幕。
- 讲解型（单人对镜头）是另一种写法：一个主场景，靠身体上的特效和贴卡突出重点，仍然先演这个人的生活状态。两种不要混着用。

### 自审（出图前必做）
把自己当成没参与设计的挑错人，逐条过：故事看不看得懂？钩子有没有冲突？有没有「每句一张幻灯片」的跳场景？每镜有没有「接上一镜什么」？道具状态前后接得上吗（桌上已两碗、手里还端一碗）？特效超过 3 处了吗？相邻机位重复吗？AI 视频难拍点（一镜换光、连做三个动作、俯拍看不到脸）有吗？写出「通过」或「不通过」，不通过就改。通过后把分镜表给学员看，【停】确认再出图。

## 第 2 步：出图、审图
- 给出图工具写一份总任务单：开头写一段「**同一套房子**」的统一装修描述（地板、墙、光线、各房间的标志物）；每镜写景别、动作、表情、产品有无、道具当时的状态；同一面镜子的镜头写「同 S01 机位」；已生成可用的图直接沿用。只写结果，不教出图工具怎么做；末尾放一条可直接复制的短执行消息。
- 产品要在场景里合成：包装与真实包装一致，有比例、落点、阴影、手指接触，不能事后平贴。只出产品的镜头也要让主角出现（手持、展示、指向）。
- 数字、图表、成分小字、价格：一律不让模型画，后期用学员原图裁切贴回。
- 画面提示词里把瓶子写成「营养片瓶 / 保健品瓶」，不写「药」；旁白原文不动。
- 空罐、倒不出东西的镜头：写明「瓶内没有可见内容物」，出图后逐张验。
- 整批重出用新文件夹（分镜图片_v2），不覆盖旧的。
- 审图重点：①几处场景装修是否一致；②动作是否接得上（该摇杯却在喝、变壮后又变瘦）；③包装字对不对、有没有多余文字；④转灰度拼总表查明暗，主体和背景分不开的镜头单独重出，调明暗对比，不靠换色相。

## 第 3 步：H3 视频提示词【停】
- 严格按 MiniMax 官方的 H3 提示词写法（GitHub：MiniMax-AI/MiniMax-H3 里的 `skills/h3-prompt-writing`）：只有首帧的镜头用首帧结构，带产品的镜头用全参考结构（首帧 + 产品清晰图）。
- 先把全部定稿首帧逐张看一遍再写，站位、道具、朝向必须和首帧一致；首帧里没有的人物、物品不要写进去。
- 视频不出人声：不写台词，写明人物嘴巴闭合、没有人说话。
- 限制里固定写：不切镜、不出现首帧里没有的新画面、不新增人物、无字幕/文字/水印/背景音乐。
- 一镜一个事件，运镜默认固定；动作按故事线写（接上一镜、引出下一镜）；特效镜头写清约束（如「液面不涨」）。
- 产品标签小字容易被画乱：能避开特写就避开，必须特写的后期贴原图。
- 每镜一个代码块，旁边用中文写镜号、对应旁白、要传的参考图顺序。H3 出片由学员自己完成，片段放回项目文件夹。

### 收片与缺镜检查
1. 取每条片段的首帧，缩小后和定稿首帧比对，再用联系表人工确认，得出「文件 → 镜号」对应表。
2. **缺**（没传）和**错**（内容不对，比如开头是 S12、半秒后切成 S13 的场景）分开报。
3. 重生成提示词只列有问题的镜，一镜一个代码块，写进 md 文件，对话里只说结论。
4. 另在 0.3/1.5/2.7/3.9/5.0 秒抽帧拼图看：动作对不对、特效有没有走样、无五官的脸上有没有长出嘴、开头有没有跳切。

## 第 4 步：配音【停】
- 文稿里数字按口播写（180加→一百八十加）；一句一个 mp3（01 到 N）；字幕特殊字按学员指定，配音读正常音。先把文稿给学员看，确认后再生成。
- 参考 `PACK/脚本/配音示例_volc_tts.py` 生成；密钥只来自环境变量，不读取、不打印、不写进文件或命令行。
- **整体语速默认 1.2 倍**（可调）。
- **每次生成都不一样**：某句读错或多字，只重生成那一句，其余保留，不要整篇重跑。
- **收到配音先查句尾截断**：每句结束前 30 毫秒的 RMS（归一化后）> 0.04 就是截断，正常在 0.01 以下。截断的句子单独补录，用 15 毫秒交叉淡化拼回，并重算后面所有句子的起点。
- 杂音或句间多出一小段能量，用 10 毫秒 RMS 包络定位，裁掉并加 30 毫秒淡出，把空隙补回去。
- 发音问题用「发音修正」解决；**字幕仍写原文**，不用修正后的字。
- 响度 -14 LUFS。生成后建议学员自己听一遍（读音、BGM 与人声平衡、句子对点）。

## 第 5 步：剪辑
先读 `风格/3D剧情带货/风格说明.md` 里的剪辑规则，并复用 `PACK/脚本/` 里的工具函数（`transitions.py` 的推拉与模糊、`sfxmix.py` 的音效混音、`check_env.py`）。`脚本/范例_渲染_CG014.py` 是阿炎风格的范例，可当底稿学结构，但字幕、转场、画布尺寸要按本风格改。

**硬规则：**
1. **时间轴以配音为准**，每镜按句长截取，不拉伸视频；偏静镜头加 3%–8% 缓推。
2. **音效只用 PACK/音效库 里的真实音效**，不用代码合成音效，也不合成环境声。放置时间 = 目标时间 − 文件峰值时间。转场和音效成对设计。
3. **响度整体 -14 LUFS**（先量后两遍 loudnorm，TP -1.5），音效总线压在人声下面，说话时 BGM 比配音低约 10 dB。交付前用 ebur128 实测。
4. **数字、图表、小字一律贴学员原图**，不重画；截图类整张放全，宁可缩小也不裁一半。
5. **BGM 用学员给的文件，从第 1 秒到结尾**，声音要够大；量能量曲线，把最大跳变点（爆点）对到产品首次出现的画面，结尾淡出 2 秒；学员换 BGM 就重新量、重新对齐。提醒 BGM 的版权和平台提示。
6. 导出 1080×1920、H.264、约 4 Mbps、AAC 192k 48 kHz 立体声。
7. 交付前自检，对不上的先改；每次改版另存新文件名（v1、v2…），渲染脚本留底；同时留一份「音效与转场时间表」md。

## 质检（逐项做完再说「好了」）
1. 抽帧拼联系表：开头、每个转场、结尾，逐张看。
2. 查响度：`ffmpeg -i 成片.mp4 -af ebur128 -f null -`。
3. 逐句核对字幕和配音：对得上、不超前、无错字。
4. 价格、贴卡、箭头、设计字是否在该在的位置。
5. 抽查拼接处和 A/B 半镜接缝。

## 合规
保健品/食品不写功效、不暗示吃了变好。学员确认「文案不改」就保留原文，只在交付时简短提示一次风险句，决定权在学员。对比画面（问题 → 改善）可以做；没过审就换镜或把旁白改软再发。

## 交付与收尾
项目文件夹固定：分镜表、出图任务单、H3 提示词（只留当前版本）、分镜图片、产品原图、H3素材（含备用）、配音（文稿、脚本、输出）、成片（含渲染脚本和时间表）、阅读说明（当前状态、用了哪些素材、缺什么）。收尾前逐项检查再说「整理好了」。项目做完后，把验证成功的新镜头写成笔记补进 `风格/3D剧情带货/`。
