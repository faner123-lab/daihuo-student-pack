# IP 带货短视频工作台（学员版）

目标：学员给一条参考视频（爆款）、产品图和产品文案，做出**自己的 IP、自己的画面**的带货视频。借鉴参考视频的节奏、转场、字幕和冲击力，不照抄它的角色和场景；画面按“镜头模板库”原创，做到同样夸张、有冲击、有暗示感。

## 素材包位置
本技能依赖《学员素材包》文件夹（里面有 脚本/、音效库/、镜头模板库/、背景/、规范/）。找它（记为 PACK）按这个顺序：①环境变量 PACK；②本机固定位置 `~/学员素材包`（Windows 是 `%USERPROFILE%\学员素材包`，安装脚本和下面的「装成自己的技能」会放在这里）；③学员拖进对话的文件夹或 学员素材包.zip（zip 先解压）。三处都没有，就让学员再拖一次。下文的路径都相对 PACK。

## 装成学员自己的技能（第一次开工时先问，只做一次）
学员不想每次都重新拖文件夹或去 GitHub 下载，就把技能和素材包装到本机：
1. 先问学员「要不要把这套技能装到你自己的 Claude 里，以后直接用？」，同意再做，不同意就跳过，别的流程照常。
2. 能运行命令的环境：把 PACK 复制到 `~/学员素材包`（已经在那里就跳过），再把 PACK/技能/ 下的每个技能文件夹（含 `h3-prompt-writing`、`h3-quanneng-cankao-zhongtu-chuxian`）复制到 `~/.claude/skills/`（Windows 是 `%USERPROFILE%\.claude\skills\`），已存在的会被更新。装完告诉学员重启 Claude。素材包里有 install.sh / install.ps1 时直接运行它们也一样。
3. 不能运行命令的环境（比如只在网页或普通对话里）：告诉学员到 Claude 设置里的技能页，把 PACK/技能/ 里的几个 zip（本风格的技能 + 两个 H3 技能）逐个上传；素材包文件夹放在一个固定位置，下次拖进对话即可。
4. 装好后告诉学员以后怎么开工：直接说「用 ip-daihuo-video-studio 技能做一条带货视频」，素材包不用再拖。

## 第 0 步：开工前检查（必做，缺哪项先补哪项，不要跳过）
用 AskUserQuestion 一次问完下面第 1、2、3 项，再跑环境检查。

### 1. 学员要提供的东西
- **参考视频**（必须，mp4）：没有就先让学员上传，不上传不开工。问清是“只借鉴”（默认）还是“照着复刻”。
- **产品**：产品正面原图（包装字清楚）+ 产品文案/口播稿。文案一字不改，只在交付时简短提示一次合规风险。
- **成片顶部合规小字**：参考视频顶部有就问保留与否（默认保留，右上角，后期加，分镜图里不画）。

### 2. IP 形象（必须有）
- 学员已有 IP：让他上传角色设定图/母图。
- 没有 IP：带他设计。问：性别年龄、体型、发型发色、标志性特征（挑染、吊坠、服装颜色）、画风（日系漫画、3D 等）、说话方式（默认闭嘴、纯配音）。然后写“IP 外貌规格”（脸、发型、眼睛、体型、默认服装、不能变的识别点、禁止项：换脸、换发型、廉价 3D、塑料皮肤、错误中文包装字），让出图工具先出一张**角色母图**（纯色底全身），学员确认后，后面所有分镜都以母图为准。IP 不得模仿真人明星或已有角色。

### 3. 配音 API（必须当面确认）
默认用火山语音合成（声音复刻）。逐项问学员：
- 有没有 AppID、Access Token、自己克隆的声音的 Speaker ID？
- 是否已设置环境变量 VOLC_APPID、VOLC_TOKEN、VOLC_SPEAKER_ID？
- **密钥在学员自己的电脑上，你（Claude）看不到他的环境变量。** 让学员在自己电脑上运行 `python3 脚本/check_env.py --only-tts --test-tts`，把屏幕上的输出（只有 [OK]/[缺失]，不含密钥）贴回对话；出现“真实合成一句配音 [OK]”才算配好。
**不要读取、打印、复制密钥内容**，只确认“存在、能调用”。克隆的声音必须是学员本人的，或已获授权，提醒一次。
没配好：告诉学员需要哪三项和怎么申请，配好前先把画面部分做完（分镜、出图、H3 提示词），配音和剪辑放后面。
分工：我写配音文稿和批处理脚本（一句一行，输出 01 到 N 的 mp3），学员自己运行；生成后我从配音文件夹读取。

### 4. 剪辑环境检查（我来跑）
在你自己的运行环境里运行 `python3 PACK/脚本/check_env.py`（渲染就在这里做，所以检查这里），把结果整理成一张“就绪清单”给学员：已就绪、缺失、怎么补。检查内容：Python 3、ffmpeg/ffprobe、numpy/Pillow/scipy、中文粗体字体（Noto Sans CJK SC Black，或设环境变量 FONT_PATH）、彩色 emoji 字体（EMOJI_FONT）、素材包里的脚本/音效/背景/模板库是否齐全。**背景音乐不在包里**，学员自备一首有明显爆点的已授权音乐。缺的先让学员补，补完重跑。

## 第 1 步：拆参考视频（自己拆，不让出图工具看视频）
1. ffmpeg scene 检测找切点：`ffmpeg -i ref.mp4 -vf "select='gt(scene,0.2)',showinfo" -vsync vfr -f null -`，取 pts_time。
2. 按 2fps 抽联系表，再每镜抽首/中/末帧，自己逐张看。
3. 逐镜记录：画面、人物表情变化、运镜（推/拉/摇/固定和强弱）、转场手法（硬切/甩糊/闪白/黑场/光圈）、字幕和花字原文。
4. 转场写成“参考手法 → 我们的做法”。参考里的主角全部换成学员的 IP，只学构图节奏、表情节奏、运镜、转场；剧情和场景原创。语音识别错字按产品名纠正，存疑的花字先问学员。

## 第 2 步：镜头模板设计（原创夸张分镜）
先读 `PACK/镜头模板库/镜头模板库_v0.md` 和参考帧总图。规则：
1. **前 3 秒必须是超现实或夸张画面**（T01–T05），不用日常写实画面开场；先给学员 2–3 个方案选。
2. **每句旁白先判断用途**（钩子、痛点、讲知识、卖点、价格、结尾），再选模板，分镜表写模板编号；同一模板全片最多两次；没有合适的自己设计并标“新”。
3. **画面要夸张**：把旁白画成视觉比喻（“全勤”画成坐在飞机机翼上）或信息画面（元素球、信息墙、搜索弹窗、全息骨骼、黑板 1、2、3）；数量要多（小怪是一群，元素球是一圈）。
4. **一句旁白一个画面为主**，只有重点句加插入镜；全片平均每镜约 1.7–2.2 秒；标 4–6 个重点镜头，停得更久并加冲击。
5. **运镜有收有放**：多数镜头基本不动，靠画面里的东西动；开场、产品登场、结尾才大推；转场约一半硬切。
6. 构图不套固定比例，避开字幕区（下方）和合规小字区（右上）。
7. 画面里的字：产品包装字用原图；信息字（元素符号、序号、梗词牌匾）可以画并逐个写清；**价格数字不画**，后期加。
8. 光色默认暖金高光，暗场全片只留 1–2 镜。

分镜表列：镜号、旁白句、模板、景别/机位、画面、表情、什么在动/运镜、产品有无、转场入、字幕（参考为准）。

## 第 3 步：分镜表独立审核（出图前必做）
另开一个没参与过前面对话的 agent，只给它分镜表和模板库，让它只挑错、不改文件：故事看不看得懂、前 3 秒够不够夸张、有没有平铺直叙的日常镜头、每镜有没有模板编号和“什么在动”、同模板是否超两次、相邻景别是否重复、AI 视频难拍点（一镜换光、连做三个动作、俯拍看不到脸、人物与多元素同时大幅运动）。最后写“通过”或“不通过”。不通过就改再审。不要让它质疑学员文案。

## 第 4 步：出图、审图
- 写一份总任务单给出图工具：每镜写景别、场景动作、表情、产品有无、可画的信息字；构图只写结果；末尾放一条可直接复制的短执行消息。立绘（透明底）和产品卡片缺就让它出，素材库里有就复用。
- 审图：只看场景和表情是否符合分镜、包装字对不对、有没有多余文字；转灰度拼总表查明暗；对照模板查夸张度。通过但与分镜有差异的，在 H3 提示词里补救。

## 第 5 步：H3 视频提示词
严格按 `h3-prompt-writing` 技能（没装就读 PACK/技能/h3-prompt-writing/SKILL.md）的结构写；产品在镜头中途才出现时，再按 `h3-quanneng-cankao-zhongtu-chuxian` 技能（PACK/技能/ 下同名文件夹）写：只有首帧的镜头用首帧结构，带产品的镜头用全参考六段结构。视频不出人声、角色闭嘴；每镜 4 秒，写首/中/末秒动作和表情变化；多数镜头写 Static，开场/产品登场/结尾大推；动作写大。出片由学员自己完成。收片后对照首中末帧给每条命名“项目号_S##.mp4”，重复和备用的放“备用”，缺镜头要告诉学员（缺的先用分镜图静图慢推占位）。

## 第 6 步：配音
文稿里数字按口播写（180加→一百八十加，25岁→二十五岁）；一句一个 mp3（01 到 N），长句按镜头拆；字幕特殊字按学员指定、配音按正常读音。参考脚本 `PACK/脚本/配音示例_volc_tts.py`。生成后处理：每句去头尾静音（只用开头静音检测 + areverse 的方法，**不要用 stop_periods**，会截断句子），整体 `atempo 1.22`（可调），句间隔 0.1 秒。

## 第 7 步：剪辑（用素材包里的脚本）
**工作目录**（WORK，建议新建项目文件夹）里放：`clips/`（H3 片段，命名 S01.mp4…）、`vo/`（处理后的 01.wav…和 dur.txt，每行“序号 秒数”）、`sfx/`（复制 PACK/音效库 全部）、`cards/`、`figs/`（立绘，去掉 alpha<20 的杂边）、`stills/`（占位静图）、`bgm/full.wav`、`grid/`（复制 PACK/背景 的视频）、`out/`。
**做法**：复制 `PACK/脚本/范例_渲染_CG014.py` 和 `范例_混音_CG014.py` 作为新项目的脚本，只改三块：①时间线（每个镜头对应哪句配音、提前 0.1 秒进入）；②镜头表 SEGS（片段起点、使用跨度、转场类型、字幕、特效）和拼贴段 GROUPS；③混音里的音效摆放和 BGM 爆点参数（BAR、DROP）。运行：`WORK=项目路径 python3 脚本/范例_渲染_CG014.py`，再 `WORK=项目路径 python3 脚本/范例_混音_CG014.py`。渲染是 Python 逐帧管道 + ffmpeg，30 秒约 1–2 分钟。
**规则**：
- 镜头时长跟配音走；片段窗口不够就往前取起点；很短的句子也要给镜头。
- 字幕只要中文，关键词黄色，放下方；有参考视频以参考字幕为准（参考没有的不加，配音照读全文）；必须和配音对得上、不超前。
- 开场：花字（约 1.4 秒）+“今天我们讲＋关键词”裂开标题，关键词跟着配音最后两个字出现。
- 转场约一半硬切（不配音效）；换场景用甩糊（竖向/横向，轻微红蓝分离）；产品登场、进拼贴用闪白糊入；换话题、进价格用黑场亮起；每 2–3 个硬切插一个糊入，不连续用同一种。详见 `PACK/规范/转场与花字规范.md`。
- 黑底拼贴段：黑色动态网格背景，立绘和产品卡片一个个独立弹入，版式多样，强调只轻放大约 7%，不用红圈红线，立绘与字幕不重叠。
- 后期元素（禁止圈、元素圆标、价格贴）用代码生成并带弹出动画；价格数字只在学员确认当前价后上屏。
- 合规小字：约 15px、白字黑描边、右上角，全程。
- 背景音乐：从第 0 秒放，爆点对齐产品登场（整体变速不超过 3%，不够就按小节循环），说话时侧链压低，整体 loudnorm 约 -14 LUFS。音效见 `PACK/音效库/音效清单.md`：只用真实音效，硬切不配，拼贴段稀疏。
- 嘴型：如果 H3 片段里角色张嘴了，剪辑时取闭嘴的那一段，实在避不开就告诉学员。
- 质检：抽帧拼联系表（开头、每个转场、拼贴段、结尾），查响度（ebur128），逐句核对字幕和配音。成片名“项目_成片_vN.mp4”，每次修改另存新版本；渲染脚本留底，新项目复制最近一个改镜头表。

## 合规
保健品/食品不写功效、不暗示吃了变好、不做对比。学员确认“文案不改”就保留原文，只在交付时简短提示一次风险句，决定权在学员。

## 交付与收尾
项目文件夹固定：分镜表、出图任务单、H3 提示词（只留当前版本）、分镜图片、产品原图、参考帧、参考视频、H3素材（含备用）、配音（文稿+脚本+输出）、成片（含渲染脚本）、阅读说明（写清当前状态、用了哪些素材、缺什么）。收尾前逐项检查再说“整理好了”。项目做完后，把验证成功的新镜头补进模板库（写清适合的旁白、画面、运镜、时长）。
