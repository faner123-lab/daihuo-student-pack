# 3D 剧情带货 · 风格说明

这份说明属于 `3d-story-daihuo-studio` 技能，写的是这个风格自己的画面和剪辑规则。通用的东西（真实音效库、响度、脚本工具）在素材包的共用部分里，这里只写本风格特有的。

## 一句话
竖屏 1080×1920，3D 写实质感。用一个连贯的小故事带货：主角在同一套房子里一路演下去，产品在一个台面上讲完，结尾回到开头的场景，状态变了。

## 与阿炎风格的差异

| 项目 | 阿炎风格 | 3D 剧情风格（本风格） |
| --- | --- | --- |
| 画布 | 横屏 1280×720 | 竖屏 1080×1920 |
| 分镜方法 | 每句旁白从镜头模板库选模板，一句可拆 2–3 个短镜 | 先写故事，一句一个镜头为主，镜头之间动作接续 |
| 场景 | 夸张、超现实、可跳场景 | 同一套房子为主，换场景要有理由 |
| 开场 | 前 3 秒必须超现实夸张画面 | 钩子要有画面冲突（失败、对比、镜前嫌弃） |
| 构图 | 不套固定比例，主角常居中大特写 | 主体居中、正面对称，避开字幕区 |
| 字幕 | 中文，关键词黄色 | 中文，白字黑边，不标黄，只用一行 |
| 画面设计字 | 花字、裂开标题 | 只给 3–5 个重点，做成物件（体重秤、优惠券、金色大数字） |
| 转场 | 一半硬切，甩糊、闪白糊入、黑场亮起 | 重叠交叉转场（xfade），同场景连续镜之间硬切 |
| 拼贴段 | 黑色网格拼贴占 35%–45% | 没有拼贴段，贴卡放在画面上方 |
| 光色 | 暖金高光 | 按场景自然光，产品段可略亮 |

## 剪辑规则（本风格）

### 字幕
- 只要中文；白字黑边（粗体，约 80 px，黑描边约 8 px，轻投影）；不标黄，不做花字。
- **只用一行**，两行会压住画面。长句拆成前后几段依次出现，每段不超过 11 个字宽（英文和数字约半个字，不从英文单词中间断开），按字数分配时间。
- 位置：底边距约 290 px。
- **字幕写配音原文**，不用发音修正后的字。
- 不加「点击购物车」之类文字。

### 画面设计字（3–5 个重点）
- 只给数字、价格、时间跳转，不写普通白字。
- 按内容设计成物件：体重 → 体重秤读数屏（深色圆角屏 + 青绿色发光数字）；克数/含量 → 金色渐变斜体大数字 + 白底小签；立减/价格 → 红色优惠券（齿孔虚线、金色大数字、微斜）；一个月后 → 白色标题 + 金色横线 + 英文小字。
- 只写文案里有的字，不加「限时」之类新词。

### 转场
- 做成真正的重叠交叉（xfade），转场放慢，约 0.35–0.5 秒（短镜 0.30 秒）。不要「一下转掉」。
- 按每镜的作用选：

| 作用 | 转场 | xfade 对应 |
| --- | --- | --- |
| 换场景 | 向左/右甩镜 | slideleft / slideright |
| 重点、特效镜头 | 放大冲击 | zoomin |
| 产品登场 | 白闪（可略长） | fadewhite |
| 情绪低落句 | 淡入黑场 | fadeblack |
| 其他 | 普通淡入 | fade |

- 同一场景里动作连续的镜头之间硬切，保持剧情连贯；A/B 半镜之间不加转场。
- **转场与音效成对设计**，不要分开做。
- xfade 链的每段输入都要 `settb=1/30,fps=30`，否则会报 timebase 错误；硬切段用 concat。

### 贴图
- 卡片圆角 + 白细边 + 投影，淡入上滑约 0.25 秒；位置在画面上部（约 y=150），底部留给字幕。
- 大数字弹出；红色向下箭头放在字幕上方，不压字幕。
- 证据贴图要加强调动效（框、放大、对勾、数字弹出）。
- 镜头震动（camera punch）只加在重点节拍（产品出现、大数字弹出）。

### 音效
- 只用素材包 `音效库/` 的真实音效，硬切不配，至少一半切点有音效。
- 选用参考：转场用「呼 / 嗖」类，产品登场和重点数字用「仙尘 / 叮」类，冲击和换话题用「砰 / 重击 / 冲击」类。详见 `音效库/音效清单.md`。
- 说话时音效压低约 8 dB。

### BGM
- 学员自备已授权音乐，从第 1 秒到结尾。量能量曲线，把爆点对到产品首次出现的画面；起点前用低能量段铺垫；结尾淡出 2 秒。

### 导出
- 1080×1920、H.264、约 4 Mbps、AAC 192k 48 kHz 立体声。

## 常见坑

- H3 生成的瓶身文字有时是乱码：能避开特写就避开，或只重出该镜，或后期贴原图。
- H3 片段分辨率较低，放大到 1080×1920 会偏软，提前告诉学员。
- 配音句尾截断、读错字，见技能第 4 步的处理方法。
- 学员的 IP 不是 3D 写实时，仍按本风格的故事和剪辑规则做，只是画面提示词里要锁定他自己的画风。

## 沉淀新做法
每做完一条验证过的片子，把好用的镜头写成一条笔记放进本文件夹：适合什么类型的旁白、画面怎么演、运镜、时长。以后新片先翻这里。
