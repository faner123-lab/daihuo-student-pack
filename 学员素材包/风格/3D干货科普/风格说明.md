# 3D 干货科普 · 风格说明

竖屏 1080×1920 的 3D 角色干货/科普视频：用你自己的 IP，在干净的摄影棚里一路做动作、演示要点，画面上有钩子标题、数字卡、进度条、关键词字幕。对应技能：`技能/3d-explainer-studio`。剪辑用 `风格/3D剧情带货/渲染模板/`（两个 3D 风格共用）。

## 和其他风格的区别

| | 3D 干货科普 | 3D 剧情带货 | 阿炎 |
| --- | --- | --- | --- |
| 内容 | 干货、科普、教学 | 带货，卖产品 | 带货，卖产品 |
| 画布 | 竖屏 1080×1920 | 竖屏 1080×1920 | 横屏 1280×720 |
| 分镜思路 | 动作演示 + 要点，参考帧法（有参考视频时） | 先写一个小故事再拆分镜 | 借鉴参考视频，原创夸张镜头模板 |
| 背景 | 默认纯黑摄影棚，黑色湿亮地面 | 连贯的生活场景 | 黑色网格拼贴 |
| 画面元素 | 钩子标题、数字卡、进度条、关键词弹出、重点词染色、可选中英双语字幕 | 贴卡、设计字（秤、金色数字、优惠券、时间跳转）、红箭头 | 花字、拼贴 |
| 转场 | 放慢，单个约 0.35–0.4 秒 | 默认速度（约 0.15–0.25 秒） | 脚本里的转场 |
| BGM | 默认不带，发布时自己加 | 对爆点 | 按技能 |

三个风格共用音效库。规则冲突时以各自风格的技能为准。

## 画面标准
- 背景：纯黑摄影棚为主，黑色湿亮镜面地面倒影，元素尽量少。整片需要场景变化时，先和 Claude 确认方向，可以大改，但要干净，不要杂乱。
- 角色：3D 质感，在此基础上叠加**轻**漫画元素（小星星、汗滴、图标气泡），不要重漫画风；加小的肢体语言，神态随旁白变化。
- 发光（健身类选题常用）：每块目标肌肉半透明着色，覆盖约 2/3，角色本身的质感仍然清楚；最多一个光环；少汗少尘无飞溅；不画写实肌纤维、不画内脏；只亮目标部位；工作中的肌肉「发力冲击感」是主视觉，不要爆炸、碎片、闪电这类夸张特效，保持克制干净的干货感。
- 肌群彩色图（整片亮点）：半透明分块着色，形状清楚，例如肩紫、胸红橙、腹青蓝、大腿橙、小腿青。
- 画面里的文字、数字、字幕一律后期加，图里不画字。
- 出图工具如果拦截，避开这些词：心脏、内脏、剥皮、砸碎、爆炸、裂开、碎片、冲击波、刺眼；改用「光环扩散」「热线」。单镜最多重试 3 次再换构图。

## 画面元素怎么写（project.json）
全部写在渲染模板的 `project.json` 里，参考 `渲染模板/project.example.fitness.json`：

| 想要 | 怎么写 |
| --- | --- |
| 强调色 | 顶层 `"style": {"accent": [255,90,40]}`，一条片子只用一个 |
| 字幕里的重点词染成强调色 | `"style": {"highlight": ["核心","腹肌"]}` |
| 中英双语字幕 | 顶层 `"lines_en": [...]`，句数和 `lines` 一样，英文在中文下面一行 |
| 钩子标题 | 第一个镜头里 `"title": "每天十分钟 练出腹肌"`（只用一个，字太长会自动缩小） |
| 进度条 | 顶层 `"progress": {"total": 6, "label": "ROUND"}`，镜头里写 `"step": 2` |
| 数字卡 | 镜头里 `"numcard": {"text": "30", "label": "秒 / 组", "delay": 0.4, "y": 760}` |
| 关键词弹出 | 镜头里 `"keywords": [{"text": "核心", "at": 0.6, "dur": 1.3, "y": 560}]`，不想要音效加 `"sound": false` |
| 转场放慢 | 顶层 `"transition_scale": 1.8`（默认 1.0） |

原则：数字卡、关键词只给真正的重点，一条片子 3–6 个就够；标题、数字、关键词都不要挡住角色。

## 转场与音效（成对设计，都在素材包里）
转场种类：`hard` 硬切、`zoom` 放大冲击、`push` 推近模糊、`hwhip` 甩镜、`white` 白闪、`longwhite` 长白闪、`black` 黑场亮起、`open` 开场。混音脚本会按转场自动配对音效，全部来自 `音效库/` 的真实音效：

| 转场 / 元素 | 音效 |
| --- | --- |
| `zoom` | 咻的一声 |
| `hwhip` | 嗖_转场1 |
| `push` | 嗖_转场2 |
| `white` | 仙尘音效 |
| `open` | 冲击_带低频 |
| `black` | 重击_短促 |
| 钩子标题滑入 | 咻的一声（轻） |
| 数字卡、关键词弹出 | 字幕音效_嘭 |

- 硬切不配音效；相邻转场换不同的转场、不同的声音；结尾只留一个重击，避免重复。
- 音效只用真实音效，不用代码合成；音效总线压在人声下面，整体 -14 LUFS。
- 开工时运行一次 `渲染模板/selftest.py`：它会先检查音效库是否完整，再把干货和带货示例都渲染、混音一遍，通过就说明转场和音效都能用。

## 字幕
- 白字黑边，单行，底边距 290 像素；超长自动拆段，字幕写学员原文，一字不改。
- 双语时中文在上、英文在下（英文自动缩小以保证不出画面）。
- 重点词染成强调色，不要整句都染。

## 常见坑
- 分镜图画成局部极近景：视频模型会自己补全身体、把镜头拉远。改成中近景，身体占画面高度约 85%。
- 台阶、残影：会被视频画成脚底错位、多一条腿。踩地动作都用平地，不要残影。
- 角色五官、体型、服饰在视频里漂移：在 H3 提示词里写五个锁定（见技能第 3 步）。
- 一个镜头塞太多硬切：改成一个较长的镜头，把连续动作、表情变化、运镜放在同一个镜头里。
