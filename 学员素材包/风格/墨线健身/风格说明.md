# 墨线健身科普 · 风格说明

横屏 1920×1080：纯黑底 + 日漫硬派墨线人物，用**你自己的 IP**。**黄 = 发力 / 主角**，**红 = 脂肪 / 危险 / 错误**，**绿 = 正确**。每句文案一张「字面演出来」的画面，字幕、标签、特写章、转场、音效、混音由 `渲染模板/` 里的脚本合成。

## 和其他风格的区别

| | 墨线健身科普 | 3D 干货科普 | 阿炎 |
| --- | --- | --- | --- |
| 画布 | 横屏 1920×1080 | 竖屏 1080×1920 | 横屏 1280×720 |
| 画面来源 | 静态墨线图（多姿势关键帧），代码做动效 | H3 生成的视频片段 | H3 生成的视频片段 |
| 画面 | 黑底 + 墨线人物 + 黄红绿强调色 | 3D 角色、黑色摄影棚 | 日系漫画、黑色网格拼贴 |
| 出片 | `渲染模板/render.py` + `mix.py` | `风格/3D剧情带货/渲染模板/` | 脚本/ 里的脚本 |
| 要不要 H3 | 不需要，只要图像工具出图 | 需要 | 需要 |

三个风格共用音效库。规则冲突时以各自风格的技能为准。

## 第一步：设计你自己的 IP（一次性）
**不要用别人的 IP。** 已经有自己的墨线 IP 就直接用；没有就让 Claude 带你设计。Claude 会用选择题问你这些，再写出图任务单发给图像工具（如 Codex、ChatGPT 图像）：

1. **主角**：性别、体型（运动型但不夸张）、发型、表情气质；身上要有**一处黄色配饰**作为「主角 = 黄」的识别点（臂章、短裤、头带、护腕任选一处）。
2. **配角**：喜剧担当大块头、路人（胖子 / 瘦小 / 上班族）。**配角身上不要有黄色**，否则会和「黄 = 主角 / 发力」串色。
3. **画风**：黑底、白色硬派墨线、少量灰度、粗细有力的线条；不写字。

产出的设定图（都要黑底）：母图（正面全身）、表情表（至少 6 个神态）、三视图（正 / 侧 / 背）、群像合影（主角 + 配角）。设定图放进你自己的项目文件夹，之后每张图都参考它们。

### 母图任务单模板（Claude 会按这个写，你可以直接用）
```
请画 1 张角色设定母图。
- 画风：日漫硬派墨线，纯黑背景，白色粗墨线勾边，少量灰度阴影，线条有力。
- 角色：<性别、体型、发型、表情气质>。身上只有一处黄色：<黄色配饰，如右上臂黄色臂章>，其余全是白线和灰。
- 构图：正面全身站立，居中，占画面高度约 80%，四周留黑。
- 画面里不要任何文字、数字、边框、水印。
- 只回复文件名。不要自检，不要回看，不要重画。
```
表情表、三视图、群像任务单照这个格式改：写明张数和每张的神态 / 角度，**每张最多带 2 张参考图（母图 + 一张别的）**。

### 审图标准（Claude 来审）
- 黑底干净，没有字、水印、边框；只有一处黄色，黄色没有出现在配角身上。
- 三视图、表情表和母图是同一个人（发型、体型、黄色配饰位置一致）。
- 不合格就写「只改这一处」的返修单；同一张图越改越怪，就参考母图从头重新生成，不再参考旧图。

## 画面图怎么出
- 每句文案出 1 张图（演字面意思）；动作示范出**同机位、同大小、同道具**的多姿势关键帧，放进镜头的 `poses`，渲染时每个子句自动换一个姿势。
- 图要求：黑底（或透明底 PNG）、人物约占画面高度一半、不画字（文字全部后期加）。
- 头和身体方向要一致（下犬式脸朝前盯着手、悬挂时身体正面但头是侧脸，都是常见错误）；头部方向要写具体，例如「脸朝正下方，鼻尖指向地面」。
- 出图工具拦截时：换说法（「仰卧屈膝」「石膏解剖教学模型」）、用代码镜像已有图、或用代码合成特写。

## 画面元素怎么写（project.json）
全部写在项目文件夹的 `project.json`，参考 `渲染模板/project.example.json`：

| 想要 | 怎么写 |
| --- | --- |
| 字幕里的重点词染成黄色 | 顶层 `"highlight": ["核心","腹肌"]` |
| 动作导航徽章 + 第 n / N 个动作 | 顶层 `"steps": 6`，镜头里写 `"step": 2` |
| 常驻记忆组件（每讲完一个动作亮一个部位） | 顶层 `"memory": ["腹直肌","腹横肌",…]`，和 `step` 配合 |
| 难度阶梯条（新手 → 标准 → 进阶） | 镜头里 `"level": 0/1/2` |
| 计次 / 计时徽章 | 镜头里 `"reps": "×12"` 或 `"30秒"` |
| 右侧标签（同一时刻只有一个） | 镜头里 `"labels": [{"text":"核心收紧","color":"yellow\|red\|green","at":0.4,"dur":1.8}]`，不想要音效加 `"sound": false` |
| 特写章（圆形放大 + 引线） | 镜头里 `"inset": {"u":0.5,"v":0.4,"r":0.12,"at":1.2,"dur":2,"y":520}`，u、v 是部位在原图里的位置（0–1），r 是半径占宽度的比例 |
| 每个子句换一个姿势 | 镜头里 `"poses": ["imgs/a1.png","imgs/a2.png"]`（单张图用 `"image"`） |
| 静止发力微颤 | 镜头里 `"tremble": true` |
| 钩子标题 | 第一个镜头里 `"title": "每天十分钟 练出腹肌"` |
| 转场 | 镜头里 `"enter": "slide\|zoom\|flash\|dim"`，顶层 `"transition_scale"` 可放慢（默认 1.0） |

## 设计规则（摘要，完整版见技能）
- 每句一个画面，直接演字面意思；画面持续有动；同一时刻只有一个标注。
- 右侧标签列固定放在画面右侧（x≈1450），不压人物、不压主角头顶。
- 字幕一次一行，每个子句一行，大字描边固定在底部，只用中文。
- 错误示范：先绿线 ✓ 正确，再闪 0.7 秒红线错误示范，再切回。
- 讲解镜头至少约 1.8 秒，更短就改连续演示 + 特写章。
- 音效只用素材包音效库里的，不合成。

## 常见坑
- 没跑 `selftest.py` 就开工：先自检，看到「自检通过」再往下。
- 配音整段合成再切：声画会对不上，一定要逐句生成，每句裁掉两端静音，得到 `vo/01.wav…` 和 `vo/dur.txt`。
- 图里画了字：文字、数字、箭头全部后期加，图里不要。
- 配角带了黄色：和主角串色，重画。
