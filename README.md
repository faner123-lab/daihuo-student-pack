# 带货短视频工作台（学员版）

用你自己的 IP、自己的画面，做出有冲击力的带货短视频：参考一条爆款，原创夸张分镜，再配音、加音效、剪辑成片。全程由 Claude 带着你做。

## 快速开始（不用装任何东西）

1. 下载本仓库（页面右上角 Code → Download ZIP，解压；或 `git clone <仓库地址>`）。
2. 新开一个 Claude 对话，把 `学员素材包` 整个文件夹拖进对话框（拖不动就压缩成 zip 再拖）。
3. 打开 `学员素材包/启动提示词.txt`，全部复制，粘贴发送。
4. 照 Claude 的提问一步步来：上传参考视频、产品图和文案，点选择题。

详细图文流程见 `学员素材包/学员使用说明书.pdf`，先读 `学员素材包/00_先读我.md`。

## 想把技能永久装进 Claude（可选）

- Mac / Linux：`bash install.sh`
- Windows（PowerShell）：`./install.ps1`

装好后重启 Claude，对它说「用带货短视频工作台做一条视频」。也可以在 Claude 桌面应用的 设置 → 技能 里上传 `学员素材包/技能/ip-daihuo-video-studio.zip`。

## 你需要自己准备

1. 一条想借鉴的爆款参考视频（mp4）
2. 产品正面图 + 产品文案
3. 你自己的 IP 形象（没有就让 Claude 带你设计）
4. 火山语音合成账号：AppID、Access Token、你自己克隆的声音的 Speaker ID。声音必须是你本人的或已获授权，密钥只放在自己电脑的环境变量里，不要上传、不要发给任何人
5. 背景音乐（有明显爆点，自备已授权的）
6. 出图工具（如 Codex）和视频生成工具（如 H3）
7. 电脑环境：Python 3、ffmpeg、numpy / Pillow / scipy、中文粗体字体（Noto Sans CJK SC Black）。不会装也没关系，开工时 Claude 会运行环境检查并告诉你缺什么
