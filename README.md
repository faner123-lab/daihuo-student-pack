# 带货短视频工作台（学员版）

用你自己的 IP、自己的画面，做出有冲击力的带货短视频。全程由 Claude 带着你做：分镜、出图任务单、H3 提示词、配音、音效、转场、剪辑成片。

## 现有风格

| 风格 | 画布 | 特点 |
| --- | --- | --- |
| 阿炎（日系漫画风） | 横屏 1280×720 | 夸张超现实画面，黑色网格拼贴，参考爆款视频借鉴节奏 |
| 3D 剧情带货 | 竖屏 1080×1920 | 先写故事再拆分镜，同一套场景里一路演到结尾 |
| 科普视频、新赛道 | 待定 | 设计中 |

两个风格共用同一套脚本、音效库和背景，各自的字幕、转场、构图规则写在各自的技能里，冲突时以风格自己的规则为准，详见 `学员素材包/规范/规则优先级与协调.md`。

## 快速开始

1. 下载本仓库（页面右上角 Code → Download ZIP，解压）。
2. 新开一个 Claude 对话，把 `学员素材包` 整个文件夹拖进去（拖不动就压缩成 zip 再拖）。
3. 复制你选的启动提示词，粘贴发送：
   - 阿炎风格：`学员素材包/启动提示词.txt`
   - 3D 剧情带货：`学员素材包/启动提示词_3D剧情带货.txt`
4. 照 Claude 的提问一步步来。

完整的图文步骤见 `学员素材包/学员操作流程.md` 和 `学员素材包/学员使用说明书.pdf`。

## 用 Cowork 或 Claude Code 自动安装（可选）

电脑上装了 git 的话，可以把下面这段发给 Claude，让它自己克隆并安装技能：

> 请把 https://github.com/faner123-lab/daihuo-student-pack 克隆到我电脑上，运行里面的安装脚本把技能装好。然后读取 学员素材包 里对应风格的启动提示词，按里面的要求带我从第 0 步开始做带货视频。

也可以自己运行：Mac/Linux 用 `bash install.sh`，Windows 在 PowerShell 里用 `./install.ps1`。会把所有风格的技能装进 Claude，装好后重启。

## 你需要自己准备

1. 产品正面图 + 产品文案
2. 你自己的 IP 形象（没有就让 Claude 带你设计）；阿炎风格还要一条想借鉴的爆款参考视频
3. 火山语音合成账号：AppID、Access Token、你自己克隆的声音的 Speaker ID。声音必须是你本人的或已获授权，密钥只放在自己电脑的环境变量里，不要上传、不要发给任何人
4. 背景音乐（有明显爆点，自备已授权的）
5. 出图工具（如 Codex）和视频生成工具（如 H3）
6. 电脑环境：Python 3、ffmpeg、numpy / Pillow / scipy、中文粗体字体（Noto Sans CJK SC Black）。不会装也没关系，开工时 Claude 会运行环境检查并告诉你缺什么

## 下载或克隆被拦截（403）怎么办
如果 Claude 报「此会话未开启对该仓库的 GitHub 访问」，这是你 Claude 环境的网络设置，Claude 自己改不了，也不会绕过。办法：在 Claude 设置里允许访问 github.com（组织账号需管理员）；或者自己点 Releases 页的 Source code (zip) 下载，解压后把「学员素材包」拖进对话，这种方式不需要任何联网权限。详见 学员素材包/学员操作流程.md。
