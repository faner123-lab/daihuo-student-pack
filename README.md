# 带货短视频工作台（学员版）

用你自己的 IP、自己的画面，做出有冲击力的带货短视频。全程由 Claude 带着你做：分镜、出图任务单、H3 提示词、配音、音效、转场、剪辑成片。

## 现有风格

| 风格 | 画布 | 特点 |
| --- | --- | --- |
| 阿炎（日系漫画风） | 横屏 1280×720 | 夸张超现实画面，黑色网格拼贴，参考爆款视频借鉴节奏 |
| 3D 剧情带货 | 竖屏 1080×1920 | 先写故事再拆分镜，同一套场景里一路演到结尾 |
| 科普视频、新赛道 | 待定 | 设计中 |

两个风格共用同一套脚本、音效库和背景，各自的字幕、转场、构图规则写在各自的技能里，冲突时以风格自己的规则为准，详见 `学员素材包/规范/规则优先级与协调.md`。

## 快速开始（一句话）

新开一个 Claude 对话，把下面这段话整段复制发送，最后一行选你要做的风格（阿炎 或 3D 剧情带货）。Claude 会自己下载、安装技能，并带你从第 0 步开始做。

```
我是带货视频课程的学员，要用老师开源的「学员素材包」做一条带货视频。

仓库地址：https://github.com/faner123-lab/daihuo-student-pack
最新版下载页：https://github.com/faner123-lab/daihuo-student-pack/releases/latest

请按下面的顺序做：

1. 把仓库下载到我电脑上（能运行命令就 git clone，否则下载最新版的 Source code zip 并解压）。
2. 如果访问 GitHub 被拦截（403，或提示「此会话未开启对该仓库的 GitHub 访问」），不要尝试绕过，也不要换镜像或缓存地址。直接告诉我三个办法：
   a. 在设置里开启对 github.com 的访问，我开好后你重试；
   b. 我自己在浏览器打开上面的下载页，点 Source code (zip)，解压后把「学员素材包」文件夹拖进这个对话；
   c. 我先添加一个放下载文件的文件夹，你用内置浏览器去下载，下载前先告诉我文件名、来源和大小，等我确认。
3. 拿到「学员素材包」后，运行里面的安装脚本，把技能装好（Mac/Linux 是 install.sh，Windows 是 install.ps1）。装不上就直接读 学员素材包/技能/ 里对应风格的 SKILL.md，照它做。
4. 然后读取 学员素材包 里对应风格的启动提示词，严格按里面的要求，从第 0 步开工检查开始带我做。每个阶段结束时用一两句话告诉我进度和我下一步要做什么，遇到「【停】」的地方一定等我确认。

我选的风格是：阿炎（横屏）
```

做 3D 剧情带货的，把最后一行改成：`3D 剧情带货（竖屏，用自己的 IP）`。

开工前 Claude 会问要不要把技能和素材包装到你自己的电脑上，同意后以后不用再拖文件夹或去 GitHub 下载。

### 如果被拦截（403）
Claude 报「此会话未开启对该仓库的 GitHub 访问」，是你 Claude 环境的网络设置，Claude 改不了，也不会绕过。按它给的办法：在设置里允许访问 github.com（组织账号需要管理员）后让它重试；或者自己打开仓库首页，点 Code → Download ZIP，解压后把「学员素材包」拖进对话，再粘贴 `学员素材包/启动提示词.txt`（3D 剧情带货用 `启动提示词_3D剧情带货.txt`）。

完整的图文步骤见 `学员素材包/学员操作流程.md` 和 `学员素材包/学员使用说明书.pdf`。

也可以自己运行安装脚本：Mac/Linux 用 `bash install.sh`，Windows 在 PowerShell 里用 `./install.ps1`。会把素材包放到固定位置，并把所有技能装进 Claude，装好后重启。

## 你需要自己准备

1. 产品正面图 + 产品文案
2. 你自己的 IP 形象（没有就让 Claude 带你设计）；阿炎风格还要一条想借鉴的爆款参考视频
3. 火山语音合成账号：AppID、Access Token、你自己克隆的声音的 Speaker ID。声音必须是你本人的或已获授权，密钥只放在自己电脑的环境变量里，不要上传、不要发给任何人
4. 背景音乐（有明显爆点，自备已授权的）
5. 出图工具（如 Codex）和视频生成工具（如 H3）
6. 电脑环境：Python 3、ffmpeg、numpy / Pillow / scipy、中文粗体字体（Noto Sans CJK SC Black）。不会装也没关系，开工时 Claude 会运行环境检查并告诉你缺什么
